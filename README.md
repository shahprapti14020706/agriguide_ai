# AgriGuide AI 🌾

AgriGuide AI is an AI-powered agriculture companion designed to help farmers make informed decisions regarding crop management, irrigation, diseases, fertilizers, market prices, weather conditions, and government schemes.

## Problem Statement

Farmers often struggle to access timely and personalized agricultural information. Important decisions related to crop health, irrigation, fertilizer usage, weather planning, and government benefits are frequently based on incomplete information.

AgriGuide AI aims to provide a single platform that delivers actionable agricultural intelligence and recommendations.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/agriguide_ai.git
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## Web Deployment

```bash
flutter build web
firebase deploy --only hosting
```
